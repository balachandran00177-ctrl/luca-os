# Security Policy — Luca OS

## Supported Versions

| Version | Supported          | Security Updates |
| ------- | ------------------ | ---------------- |
| 1.0.x   | :white_check_mark: | Active           |

## Reporting a Vulnerability

We take the security of Luca OS and its users very seriously. If you discover a potential vulnerability in any Luca OS tool, helper script, or configuration overlay, please follow these steps:

1. **Do not disclose publicly:** Do not open a public issue before the issue has been assessed and patched.
2. **Contact:** Email details to `security@lucaos.local` or open a confidential security advisory on GitHub.
3. **Include Details:**
   - Affected script, tool, or configuration
   - Step-by-step reproduction instructions
   - Potential impact (privilege escalation, sandbox escape, network exposure)
4. **Response Timeline:** We acknowledge security disclosures within 48 hours and work with reporters to develop and verify patches before public release.
